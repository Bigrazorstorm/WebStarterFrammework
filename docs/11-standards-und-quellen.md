# Standards und Quellen

Referenzstand: 9. Oktober 2026. Projektvorgaben sind keine automatische Zertifizierung und keine individuelle Rechtsberatung. Rechtliche Anwendbarkeit wird je Betrieb gesondert geklärt.

- W3C WCAG 2.2: https://www.w3.org/TR/WCAG22/ — technisches Ziel AA, manuelle und automatische Prüfung.
- W3C Erläuterungen: https://www.w3.org/WAI/WCAG22/understanding/ — Hilfen zur Auslegung; normative Kriterien bleiben maßgeblich.
- OWASP ASVS: https://owasp.org/www-project-application-security-verification-standard/ — Version 5.0 als Ausgangspunkt für projektbezogenen Sicherheitsprüfkatalog.
- Google Search Essentials: https://developers.google.com/search/docs/essentials — Voraussetzungen der Auffindbarkeit; keine Rankinggarantie.
- Google technische Anforderungen: https://developers.google.com/search/docs/essentials/technical
- HTML Living Standard: https://html.spec.whatwg.org/ — Implementierung vor Auswahl neuer APIs auf Browserunterstützung prüfen.

Konkrete Tool- und Frameworkversionen werden erst nach Technikentscheidung festgelegt. Eigene Budgets (z. B. JavaScriptgröße) sind ausdrücklich Projektstandards.
